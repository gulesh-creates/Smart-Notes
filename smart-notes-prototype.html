Sync & Offline Architecture

Preview / Planned Feature
Cross-device cloud synchronization will activate in the production build with secure accounts. Currently operating 100% offline on this device via IndexedDB.

Planned Production Behavior

  • Local-First Guarantee: Every edit is written to on-device SQLite (Android) and IndexedDB (Web) before any network call.
  • Zero-Loss Offline Mode: Works seamlessly on airplanes, subways, or offline environments.
  • CRDT Auto-Merge: Concurrent edits on mobile and desktop auto-converge cleanly.
  • End-to-End Encryption: Notes encrypted with device keys; server cannot read your thoughts.
